## 🎯 Overview

> **WEBHUNTER** is a Python-based **web security reconnaissance and simulation framework** designed for **bug bounty hunters, penetration testers, and security researchers**. It combines multiple recon modules into one streamlined tool with a clean, hacker-style terminal interface.

Whether you're mapping a target's attack surface or hunting for misconfigurations — WebHunter gives you the **edge you need**.

<div align="center">

|:---:|:---|:---|
| 🕸️ | **Information Gathering** | Collects target intel efficiently |

## 🎯 Usage

```bash
# Basic hunt
python start.py --target https://example.com

# Custom wordlist
python start.py --target https://example.com --wordlist endpoints.txt

# Multi-threaded hunt
python start.py --target https://example.com --threads 20

# Save report
python start.py --target https://example.com --output reports/hunt.json

# Full power mode
python start.py --target https://example.com --threads 50 \
                --wordlist endpoints.txt --output reports/hunt.json --verbose
```

### CLI Flags

| Flag | Description |
|:---|:---|
| `--target` | Target URL |
| `--wordlist` | Path to endpoint wordlist |
| `--threads` | Number of threads (default: 10) |
| `--output` | Report output path |
| `--verbose` | Enable verbose logging |
| `--help` | Show help menu |

## 🧠 How It Works

```mermaid
graph TD
    A[Start] --> B[Load Config]
    B --> C[Parse Endpoints]
    C --> D{Start Threads}
    D --> E[Mock Request]
    E --> F{Response Analysis}
    F -->|Vulnerable| G[Log Finding]
    F -->|Safe| H[Next Endpoint]
    H --> E
    G --> I[Generate Report]
    I --> J[Done]

    style A fill:#001100,stroke:#00FF41,color:#00FF41
    style G fill:#001100,stroke:#00FF41,color:#00FF41
    style J fill:#001100,stroke:#00FF41,color:#00FF41
```

1. **Load** — Reads endpoints and config
2. **Dispatch** — Sends requests to target
3. **Analyze** — Checks status codes, headers, and body
4. **Log** — Saves findings to JSON report
5. **Report** — Displays a clean, structured summary

## 🔥 Power User Tips

### Combine with Other Tools

```bash
# WebHunter + subdomain enumeration
subfinder -d target.com | httpx | while read url; do
    python start.py --target "$url"
done

# WebHunter + nuclei
python start.py --target https://example.com -o recon.json
nuclei -u https://example.com -t ~/nuclei-templates/
```

### Speed Optimization

```bash
# Stealth mode (slower but safer)
python start.py --target https://example.com --threads 2 --delay 1

# Full power mode
python start.py --target https://example.com --threads 50
```
